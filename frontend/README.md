# Loan Platform Frontend

This repository contains the Vue3 frontend for the Loan Platform application. It includes a simple loan application form, API integration using Axios, Vuex store, and routing.

## Project Structure

```
frontend/
├─ src/
│  ├─ api/          # Axios API services
│  ├─ components/   # Reusable Vue components
│  ├─ views/        # Page components
│  ├─ store/        # Vuex store
│  ├─ router/       # Vue Router configuration
│  ├─ main.js       # Application entry point
│  └─ App.vue       # Root component
├─ index.html
├─ vite.config.js
└─ package.json
```

## Running the Project

```bash
# Install dependencies
npm install

# Run development server
npm run dev
```

The app will be available at `http://localhost:3000`.
